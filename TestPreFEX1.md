# Test Pre FEX 1

Create an app DaustBlog (or Expo Router) with two screens: `BlogList` and  `BlogDetails`.

- Fetch posts from `https://jsonplaceholder.typicode.com/posts`.
- Display the first 7 posts.
- Tapping a post navigates to `BlogDetail` passing the post ID.
## Deep Linking

- Setup a deep link that allows an external URL to open a specific post directly.
- Example URL:* `daustblog://details/5` should open the app directly to the details of post #5.
## Theme Switcher
- A simple button on the `BlogList` header that toggles the background color between Black and Wite.

## Deliverables
- apk build
- github link of the app
